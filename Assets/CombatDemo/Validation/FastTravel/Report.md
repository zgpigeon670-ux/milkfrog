# 篝火快速传送验证

日期：2026-09-25。Unity 6000.6.2f1；命令行测试和构建在独立项目副本进行，未使用 Computer Use 或正式用户存档。

## 行为

- 在篝火休息即点亮该篝火；只有已点亮的其他篝火会出现在“快速传送”列表。初始起点篝火和旧版 v2 存档的当前复活点可用。
- 只能在安全脱战、角色 `Neutral` 且位于篝火菜单时传送。抵达后补满生命、清空架势、重置普通小怪，并以目的地作为新的复活点。已击败 BOSS 保持死亡。
- 先写入目的地安全存档，成功后才移动角色、更新复活点；写入失败保持原位置、资源和复活点。传送列表保存在现有 v2 JSON 的可选字段中，旧 v2 存档缺少该字段时会恢复起点和当前复活点。
