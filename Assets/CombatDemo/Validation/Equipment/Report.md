# MILKFROG 装备背包与 3D 角色面板

2026-10-14 · Unity 6000.6.2f1 · 本地 `codex/inventory-equipment`。本轮基于现有未提交的消耗品、镜头及动画修复工作区，未推送或合并 GitHub。真实键鼠验收由用户完成。

## 功能与操作

Tab 开关背包，Esc 返回上一层，暂停菜单保留入口。左侧“全部／装备／消耗品／任务”网格支持无限堆叠、滚轮与方向键选择；下方显示名称、数量、可滚动说明和固定装备对比。右侧显示独立 3D 角色、五个装备部位、生命／架势／等级／成长／伤害／防御／负重／速度，以及三消耗品槽和三技能占位槽。鼠标拖动预览旋转，不驱动世界相机；预览按 UI 宽高比渲染，世界与战斗动画保持暂停。

头、身、腿、鞋各有一件基础装备，在 `(-3/-5/-7/-9, 0.02, -30)` 一次性拾取 ×1，不自动穿戴。默认剑纳入背包与武器槽，不可卸下，保留原模型、动作和轨迹。点击部位筛选，再用“穿戴／卸下”操作；装备始终引用背包条目，不复制或扣数量。只有打开前已脱战、Neutral 且无顿帧才能换装，资格在清理输入前记录。护具用可编辑几何占位，同步到世界角色和预览的 Generic 骨骼；没有修改 FBX 或蒙皮。

消耗品在背包指定槽 1／2／3，局内数字键选槽、Q 使用；数字键与 Q 同帧先选择，多个数字键按 1／2／3 优先。选择可在攻击或顿帧期间进行，但 Q 仍只在 Neutral／Guard 且无顿帧生效，不缓存、长按不重复。菜单内数字键和 Q 无效，关闭后须重新按下。闪避优先于用药，成功用药拦截同帧攻击，不打断防御。同一种药重新指定时移动绑定；耗尽保留 ×0，不自动换药。HUD 同时显示三槽、当前选中与独立战意倒计时。进关默认槽 1，死亡／休息／传送保留本局选择；选中索引不即时写盘。三个技能槽显示“未开放”，没有实际技能或按键。

## 属性与持久化

| 装备 | 重量 | 默认效果 |
|---|---:|---|
| 练习头盔 | 1 | 护具防御 +5 |
| 练习胸甲 | 3 | 护具防御 +12 |
| 练习护腿 | 2 | 护具防御 +8 |
| 轻便鞋 | 0 | 水平移速 +10% |
| 默认练习剑 | 2 | 基础伤害 10，格挡防御 20 |

只有穿戴的护具与武器计重，背包库存不计重。水平速度 = 基础速度 × clamp(1 − 重量 × 2% ＋ 鞋加速, 40%, 150%)；闪避距离、无敌窗口、跳跃、动作时序不变。护具生命减伤 D/(100+D)、武器格挡架势减免 G/(100+G)，最高 80%。全套重量 8、护具防御 25、生命减伤 20%、格挡减架势约 16.7%、移速 3.76（基础 4）。成功格挡仍不扣生命，普通命中架势、弹反奖励和危险攻击规则保留。

武器伤害按动作原系数 × 武器倍率 × 成长 × 战意计算，攻击提交捕获；默认轻斩 10、追击 12、突刺 10–22。换装只修改装备修饰，不重置生命、架势、计时或药效。战意计时依然暂停冻结，在死亡、休息、传送、载入及通关重置时清除。

`ItemDefinition` 保留原分类值并追加 Equipment；配置部位、重量、防御、基础伤害、鞋加速和外观。`EquipmentService` 管理五部位，`CharacterStatsCalculator` 为实际移动、核心战斗和 UI 提供共同数值。`InventoryData.quickSlots` 保存三绑定，`equipment.slots` 按头／身／腿／鞋／武器保存五引用；旧 `equippedItemId` 保留作槽 1 兼容字段。数量与绑定使用独立快照，不共享可变数组。

存档 v6：v1–v5 沿原迁移路径保留世界、任务与数量；只有 v5 旧 Q 绑定迁至槽 1，其他旧版本快捷槽为空。默认剑只补齐一份并装备，护具与消耗品不补发，重复迁移不复制。所有保存路径保留装备与三绑定；未知 ID 原样保留并显示配置缺失，不计入装备属性。缺少 v6 关键字段或数组结构无效时拒绝主档并恢复完整备份。临时增益不保存。

装备、槽位配置、拾取和用药均先写盘再生效，失败不改数量、属性、外观或恢复效果；战斗配置槽位与用药保留最近安全档的位置和资源。

配置：`Settings/Items`；几何：`Prefabs/Equipment`；拾取：`Prefabs/MVP/pickup-*.prefab`；界面：`UI/Inventory/InventoryView.prefab`。`EquipmentVisualPart.boneName` 和 `EquipmentVisuals.modelRoot` 是可编辑 Generic 挂点。升级工具重复运行不重复添加、不覆盖已有物品数值或装备几何，检查物品／世界 ID、引用、数量、部位、骨骼及多余 Collider。没有装备强化、耐久、随机词条、制作、商店、丢弃或徒手系统。

## 试玩交付

运行 `Builds/MilkfrogMVP-Equipment/MilkfrogMVP.exe`，保留 Data、UnityPlayer.dll、MonoBleedingEdge 与字体许可证等同目录文件。可附加 `--mvp-save-dir <独立目录>` 隔离试玩存档。

1. 出生点拾取四件装备与三种药；确认重复回到拾取点不会再次领取。
2. Tab 打开背包，点击部位筛选；穿戴／卸下，观察角色、对比数值及移速变化。默认剑不可卸下。
3. 在预览区域拖动，确认角色可旋转、世界和镜头冻结；用方向键／Enter 操作网格、装备与快捷按钮。
4. 为三种药指定三个槽，关菜单后按 1／2／3，再 Q；长按不重复，菜单关闭需要重新按下，空槽或 ×0 不自动换药。
5. 战斗中查看背包但无法换护具；Neutral／Guard 可用药。攻击／蓄力／闪避／受击中 Q 不缓存，闪避同帧优先。
6. 休息、死亡、传送和重进，确认数量、五部位与三绑定保留，战意清除；重进默认槽 1。
7. 切换三档分辨率，检查文字、长说明、模型比例、六槽与血条／架势／交互提示的布局。

以上为工程验证和自动画面检查；真人键鼠手感与完整通关尚待用户验收。
