# 篝火复活与角色成长验证

日期：2026-09-24。Unity 6000.6.2f1，独立验证副本。未使用 Computer Use；正式用户存档未用于自动化。

## 实现与边界

- `MVP_TestLevel` 增量加入 `camp-start`、`camp-before-boss` 两处篝火。编辑器入口 `Tools/Combat Demo/Upgrade MVP Bonfires` 幂等地补入缺失对象与引用，不重建关卡。
- E 在安全脱战 `Neutral` 且 2.5m 内休息：写盘成功后才激活、补满资源、重置小怪。死亡在最近篝火满血、零架势复活，保留经验与属性；BOSS 击败标志永久保留。
- 经验、等级、三项成长和篝火 ID 纳入 v2 JSON 存档。战斗奖励只覆盖最近安全档中的成长数据，不写入战斗位置或动作。v1 档读取时保留原进度，旧通关档补发一次 200 经验；首次 v2 写入时同步转换备份。
- 攻击成长只在本次攻击快照上缩放生命、命中架势、格挡架势伤害，未修改共享攻击资产或弹反惩罚。
- HUD 增加生命／架势数值、等级／经验和篝火提示；篝火菜单负责加点，C 和暂停菜单打开只读属性页。中文采用项目已有 Noto Sans SC。
