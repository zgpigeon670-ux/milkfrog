# 第四阶段：MVP 交付与验证

日期：2026-09-24。Unity 6000.6.2f1 / URP / 新 Input System。

## 启动与交付

- Unity 入口：`Assets/CombatDemo/Scenes/MainMenu.unity`。点击 Start Game / Continue 进入 `MVP_TestLevel`。
- Windows 入口：项目根目录 `Builds/MilkfrogMVP/MilkfrogMVP.exe`。必须保留整个同级 Data 与依赖文件；构建从首页启动。
- 游戏拥有三只巡逻小怪与一只 BOSS。出生点在平地南侧，BOSS 在北侧棕色区域，靠近 8m 触发。
- WASD 移动、鼠标转镜头、中键锁定／解锁、空格垫步、左键普通攻击／连击／蓄力突刺、右键防御／弹反、Esc 暂停、F2 调试。R 与 F1 仍只属于旧训练场。
- 菜单为英文占位，使用 Unity 内置字体；没有增加模型、音频、外部包或许可证依赖。

## 实现与配置

游戏流程 `MainMenu / Loading / Playing / PlayerDead / Victory`，遭遇状态 `Exploration / NormalCombat / BossCombat`，现有角色动作状态机三者分离；暂停为独立标志。

`GameFlowController` 负责首页、场景切换、暂停、保存与结算。`MvpWorld` 管理输入、角色注册表、1/120 秒子步推进和一次性反馈分发。`EncounterDirector` 管理参与敌人集合；`LockOnController` 负责屏幕目标选择。血量与架势只能通过核心的恢复接口或原命中结算修改。

`MobEnemy` 与 `BossEnemy` 继承 `EnemyController`，各自拥有 Prefab 和独立配置，运行时复制数值避免修改共享资产。调参位置：

| 配置 | 用途 |
|---|---|
| `Settings/AnimatedCombat.asset` | 当前玩家战斗默认规则与移动速度；保留已有连击等调整 |
| `Settings/MobEnemy.asset` | 小怪生命 100、架势 100、速度 2.5、警戒 6m、巡逻半径 3m、追击外扩 12m |
| `Settings/BossEnemy.asset` | BOSS 生命 600、架势 300、速度 3、攻击等待 1 秒、触发半径 8m |
| `Settings/BossSlash.asset` | 独立攻击：伤害 25、命中架势 25、格挡架势 40、0.45/0.10/0.40 秒 |
| `Prefabs/MVP` | Player、MobEnemy、BossEnemy；生成新敌人后 stableId 必须唯一 |

小怪命中规则、动画与伤害沿用实施时训练场配置。没有修改原两张训练场文件。保留高架势 BOSS 的单次崩溃处决，不制作多阶段招式。

探索时每秒恢复 5 生命、20 架势，不与核心架势恢复重复累加。普通交战中所有有效命中、格挡、弹反、处决刷新 10 秒计时；空挥和无敌忽略接触不刷新。超时归位后必须离开再进入警戒范围才会再次靠近触发；主动攻击可重新引战。越过追击边界归位期间受保护，归位补满资源。BOSS 战启用场地边界与强制锁定，普通脱战规则失效。

中键按可见屏幕目标到准星的像素距离排序，候选距离 20m；死亡、超过 25m 或遮挡持续 1 秒解除普通锁定。未锁定仍可攻击与处决。小怪头顶条在 20m 内显示，屏幕后或遮挡时隐藏，避免远处标签堆叠；BOSS 使用独立大条。

## 安全存档

默认位置：`Application.persistentDataPath/MilkfrogMVP/save.json`，备份为 `save.backup.json`。保存版本、关卡、玩家位置／朝向、生命／架势、已击败敌人 ID 和 BOSS 通关标志。

只在脱战且 Neutral 时保存；新游戏、脱战、胜利自动保存，探索每 15 秒自动保存，也可通过暂停菜单保存。临时文件替换主档，保留备份；主档损坏或无法读取时尝试备份。损坏文件不会在读取时被覆盖，下一次写入时归档。失败显示提示，安全返回首页／退出时保存失败会提供重试或放弃保存选项。

读档清除锁定、仇恨、攻击、蓄力、顿帧和反馈；未击败敌人恢复出生位置与默认资源，已保存死亡敌人不再出现。死亡回到最近存档的血量，不额外补满。战斗中退出不覆盖安全档。越界或落入未结束 BOSS 触发区的位置回退安全出生点。

本轮自动化和截图使用随机临时存档目录。独立程序验收使用专门的 `StandaloneAcceptanceSave`；开发构建支持 `--mvp-save-dir <目录>`，无需修改正式存档。

## 编译、自动化与实际画面

实施前重新建立基线：**44 项 Edit Mode + 37 项 Play Mode，81 项通过**，不是复用历史 71 项报告。

新增存档测试 8 项，MVP Play Mode 测试 15 项。最终结果为 **52 / 52 Edit Mode、52 / 52 Play Mode，共 104 项通过**。证据：[EditMode.xml](EditMode.xml)、[PlayMode.xml](PlayMode.xml)、[构建与运行记录](ExecutionEvidence.txt)。覆盖内容包括：

- 存档往返、只剩备份、主档被文件锁占用、双档损坏保留、腐坏归档、版本／数值校验及写入失败。
- 新开局、玩家资源与击败 ID 恢复、无瞬间动作残留、越界回退、死亡读档重试。
- 多参与者、单个死亡不中止世界、阵营过滤、反馈不重复、10 秒边界及再警戒、有效交互计时刷新、越界停止旧攻击。
- 30／60／120 FPS 下恢复速率与脱战边界一致；暂停停止恢复。
- 中键绑定、准星排序、遮挡筛选和解除、目标死亡、无敌人镜头、顿帧松键不补发。
- BOSS 强制锁定、不能超时脱战、场地碰撞、胜利保存、双方同时死亡按玩家失败处理。
- 首页继续、新游戏覆盖确认、反复场景切换、暂停菜单、仅一个会话和 EventSystem。

UI 测试使用真实按钮回调和 Input System 虚拟设备，不等于真人按键手感。旧战斗测试一并执行。
