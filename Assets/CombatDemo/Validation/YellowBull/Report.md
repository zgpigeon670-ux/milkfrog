# 黄牛·踏地：实施与验证报告

2026-10-15 · Unity 6000.6.2f1 · 本地 `codex/yellow-bull-boss`。保留当前持剑 BOSS、背包装备和动画修复，不推送或合并。真人键鼠与完整体验验收尚待用户完成。

## 已实现

- 主菜单直接进入“黄牛试炼”；主线暂停菜单新增入口，仅在打开暂停前已脱战、Neutral、无顿帧时开放。资格在清理防御或蓄力输入之前记录。
- 黄色拟人牛，短角、宽鼻、圆钝脸与厚实体型，不持武器。独立低模、18 骨骼、11 动作、7 种角色材质；碰撞高度 3.6，约为玩家控制器的 1.8 倍。
- 生命 600、架势 300，不主动格挡或弹反，普通命中不会连续打断。保留架势崩溃与处决。
- 五招：可格挡／弹反的牛角横顶与后蹬，以及需躲避的冲撞、锁定落点砸地、扩散震波。震波可跳越，越过后的内圈不会持续造成伤害。身体接触本身不造成伤害。
- 冲撞出发前 0.25 秒锁向、砸地命中前 0.4 秒锁定落点，随后停止跟踪。后蹬只在玩家处于后方且冷却结束时触发。
- 生命首次降至 50% 后完成当前动作，再以可受伤的咆哮进入二阶段。增加双冲撞、间隔 0.65 秒的双震波，伤害不加倍；同一攻击不会连续超过两次，双段招式计入次数。
- 每段攻击独立去重；双震波使用独立命中组，沿用核心减伤、无敌、格挡与命中反馈。被弹反、架势崩溃或死亡时，取消当前招式、后续段与预警。
- 预警线与判定共享招式几何配置；牛的危险提示采用顶部小提示，避免遮挡动作。三个快捷消耗品槽、Q 使用和背包沿用当前系统。
- 独立圆形场地半径 18 米，镜头可旋转、牛锁定点在胸部，增加大型敌人镜头距离。AI、动画、位移、预警及判定使用模拟时间，暂停、背包和顿帧同时冻结。

已检查作者公开发布的 KayKit 动作包。取得的免费样本没有独立腿骨，不适合黄牛后蹬和震脚，因此按方案允许的备用路径自制全部动作，没有把样本或旧 BOSS 动作当作新动作交付。来源、样本版本和公开许可页见 `Sources.md`。

编辑器菜单 `Tools/Combat Demo/Upgrade Yellow Bull Trial` 增量补齐资产与构建场景列表，保留已有招式、材质和场景配置；不会重新运行建模脚本。原 MVP 构建入口也会包含已存在的黄牛试炼场景，避免菜单入口在常规构建中失效。

## 存档与返回

进入时深拷贝当前角色的成长、装备、物品数量和三槽绑定；没有可用存档时使用基础角色、默认剑和三种药各 3 份。挑战使用 `SaveService` 内存模式，保留现有事务接口，但不创建、覆盖或恢复主线文件。

每次重试从入场快照重新复制，恢复满生命、零架势、入场库存与绑定，清除临时增益，默认选槽 1。胜利不发放主线经验、不推进任务。死亡和胜利均可再次挑战或返回；从暂停进入会恢复进入前位置、生命、架势、成长、数量、装备和选槽，从主菜单进入则返回主菜单。回到主线后正常的探索恢复逻辑继续运行。

主线仍为 v6；新场景名称通过独立会话路由，未写入主线存档，也没有增加存档迁移。

## 真人试玩清单

1. 保留构建目录的 Data、UnityPlayer.dll、MonoBleedingEdge 和字体许可文件，运行 exe，主菜单选择“黄牛试炼”。可用 `--mvp-save-dir <独立目录>` 指定试玩主线存档位置。
2. 向前靠近黄牛开始战斗，检查其外形、动作与原剑士明显不同，鼠标始终可以转动镜头。
3. 看低头和刨地动作，侧闪冲撞；检查方向锁定后不会继续追踪，冲撞结束存在反击窗口。
4. 绕到背后观察后蹬；角击、后蹬尝试格挡和弹反，红色预警攻击使用走位或闪避。
5. 观察砸地落点停止追踪、扩散环内外安全区，尝试跳过震波。把生命压到一半后观察咆哮、双冲撞和双震波节奏。
6. Tab 背包及 Esc 暂停，检查模型、危险预警、位移和计时冻结；关闭后不误攻击、不误用药。
7. Q 消耗药品后死亡并重试，检查恢复入场库存、满生命和槽 1；胜利后重试也一样。
8. 从主线暂停进入后返回，检查位置、资源、装备与选槽；比较主线与备份文件，挑战不改变主线存档。
9. 检查三档分辨率的血条、提示、预警、模型、背包和六个快捷／占位槽。实际难度、攻击读招与键鼠手感由用户验收。
