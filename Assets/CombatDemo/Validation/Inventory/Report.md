# MILKFROG 道具背包验证与试玩

2026-10-02 · Unity 6000.6.2f1 · 本地分支 `codex/inventory-system`。

已实现道具背包、UGUI 网格与详情、通用拾取、两种消耗品、任务钥匙接入和 v4 存档。自动化使用独立项目副本与临时存档，没有使用 Computer Use，没有进行真人键鼠试玩，也没有读取或覆盖正式玩家存档。代码没有推送到 GitHub。

## 实现与资产

- B 打开／关闭，Esc 返回游戏或原暂停／篝火菜单。暂停菜单增加背包入口。打开时暂停战斗、敌人、手动动画图和镜头平滑跟随。
- 左侧“全部／消耗品／任务物品”和不限格数的滚动网格，右侧图标、中文说明、数量、效果与使用按钮；支持鼠标、滚轮、方向键导航与 Enter 确认。键盘选择会将目标格子滚入视野。
- 出生点左前方 `(-3, 0.02, -33)` 放置疗伤药 ×3，恢复 40 生命；更远的左前方 `(-6, 0.02, -33)` 放置定心丸 ×3，降低 40 架势。使用和拾取数量可编辑，两处物品各领取一次。
- 打开前处于 Neutral／Guard 才能使用，顿帧、攻击、蓄力、闪避、受击、架势崩溃和死亡无法使用。恢复接口只修改生命／架势，不重置动作、攻击 ID 或弹反计时。生命已满或架势为零不消耗。
- 关闭菜单清除未提交输入，并拦截尚未松开的鼠标攻击；松开并重新按下后才发起攻击。关闭时仍沿用现有清理规则，未完成蓄力会取消。
- 守门钥匙显示在任务分类，开门检查背包持有量；开门后保留，不能使用或丢弃。原世界获取事实继续驱动任务进度，不作为消耗品数量来源。

配置位于 `Settings/Items`；可编辑背包 Prefab 位于 `UI/Inventory/InventoryView.prefab`；拾取 Prefab 位于 `Prefabs/MVP/pickup-healing-medicine.prefab` 和 `pickup-calming-pill.prefab`。配置目录、界面和两处拾取物增量加入 `MVP_TestLevel`，已有敌人、钥匙、门及篝火布局保留。

`Tools/Combat Demo/Upgrade MVP Inventory` 只补齐缺失配置、Prefab 引用和实例。重复执行不改写已有场景字节，不覆盖作者配置。构建验证检查重复／缺失物品 ID、拾取稳定 ID、缺失目录引用／图标／说明、非法效果数值和不完整界面引用。

## 数据与保存

- `ItemDefinition` 是物品目录；`InventoryService` 是当前持有数量的唯一所有者，提供添加、查询、消耗、变更事件与深复制快照。`InventoryData.entries` 保存稳定 ID 和正整数数量，排序后写盘。
- 拾取通过现有 E 交互筛选与再校验，先原子写入背包和世界拾取事实，再发放并隐藏视觉对象；失败保留原数量、物品与任务事实。
- 使用先提交拟扣除的数量，再应用恢复效果。脱战且 Neutral 时保存当前位置及恢复后的生命；其余合法使用状态只更新最近安全档的背包／世界事实，保留安全位置、生命和架势。读盘或写盘失败不扣物品、不恢复资源。
- 死亡、战斗经验保存、休息、传送、手动保存及重新进入游戏均保留背包，不自动补充消耗品；新游戏为空背包。
- v1／v2 先执行已有世界进度迁移与一次性奖励规则，再迁移背包；v3 原有钥匙、门、任务和成长数据保留。历史关键物品各补入一个，不赠送消耗品，重复读写不会再次发放。
- v4 缺失背包字段、空 ID、重复 ID、非正数量或空背包结构视为无效，继续使用原有主档／备份恢复与损坏文件保留机制。暂缺配置的物品数量保留，在“全部”分类可查看 ID，无法使用。

## 真人试玩清单

1. 从首页进入关卡，按 B 检查空背包；关闭后在出生点左前方按 E 拾取两组道具，确认分别 ×3，重复拾取无效。
2. 按 B 查看分类、图标和说明；用鼠标、方向键及 Enter 操作，再从暂停菜单进入背包并按 Esc 返回。
3. 与小怪交战并受伤，在可行动时按 B，确认敌人、角色动作和镜头冻结；使用疗伤药后确认恢复与扣数量。架势高时使用定心丸，满血／零架势时检查禁用提示。
4. 在攻击、蓄力、闪避或受击期间按 B，确认只能查看。关闭背包时继续按住鼠标，确认不会立刻挥刀；松开重按后恢复攻击。
5. 拾取守门钥匙，查看任务分类，再点亮守门篝火并开门，确认钥匙仍为 ×1，任务和 BOSS 门禁流程正常。
6. 记录剩余数量，分别休息、传送、死亡重试、返回首页继续，确认数量未补满、拾取物未重生。检查小窗口及全屏阅读效果。

首版不包含装备、快捷栏、制作、商店、重量、丢弃或道具使用动画。最终手感和独立构建试玩由用户验收。
