# 战斗视角、UI、反馈与判定验证

日期：2026-09-23。Unity 6000.6.2f1 / URP / Windows。

## 本轮修改

- 动画场景相机按玩家朝向平滑跟随背部，从右肩侧取景，保留双方构图、SphereCast 避障、局部冲击和重置归位。
- 新增独立 `CombatHud`。敌人生命在左上、敌人架势在上方中央；玩家生命在左下、玩家架势在下方中央。红色血条、延迟伤害尾条、由中央展开的金色架势条、崩溃提示与胜负提示均不依赖 F2。视觉布局参考只狼，全部 UI 图形由本项目绘制，未提取游戏资产。
- F2 默认关闭，只控制调试面板、世界状态标签和地面预警框。
- 新增 `Milkfrog/Combat Fighter` shader。完美弹反时，被弹开的攻击者全身闪白并在 0.20 秒内渐退；普通命中使受击者泛红。MaterialPropertyBlock 控制效果，不逐次创建材质。
- 8 组可复用的放射状火花区分普通命中、格挡和弹反。弹反保留 0.04 秒局部顿帧、合成音效和较强镜头冲击。重置清理闪白、火花、声音和冲击。
- 动画场景的攻击沿实际模型和剑尺寸烘焙的 65 个刀刃姿势扫掠，补齐大时间步跨越有效期的检测。多 Collider 共用核心去重；攻击被弹反后立即停止剩余扫掠。
- 加入墙体遮挡、高度和朝向检查，处决也遵守这些限制。2m 是核心范围上限，实际剑刃触不到就挥空；AI 接敌距离校准为 1.25m。
- 攻击淡出保留末次姿势，移动防御只覆盖上身，腿部继续步行；后退反向播放步态。动画根位移继续锁定。

## 尚需真人体验与限制

- 镜头平滑速度、越肩距离、闪白强度和音量仍需真人持续绕敌、贴墙和反复攻守体验；没有把自动化测试称为人工验收。
- 刀刃路径与当前动画、模型缩放和剑尺寸绑定。改动这些资源后必须重新烘焙。当前只支持单敌人、单段挥剑；没有加入连招、闪避或复杂处决对位。
- 本轮未重新执行六轮各 60 秒的性能对照。此前 `Validation/Animated` 的性能数字仅代表旧版本。性能工具显式打开诊断 UI，确保新默认隐藏调试面板后仍能测量相同的缓存工作负载。
- 批处理构建/截图进程退出时 Unity 报过原生 `JobTempAlloc` 清理警告，尚未定位来源；最终截图进程还出现 `UnityEditor.Search.SearchDatabase` 索引越界异常，但构建成功且四张截图全部完成。未发现战斗脚本异常或 shader 编译错误。不据此宣称 Editor 原生内存和索引系统检查已通过。
