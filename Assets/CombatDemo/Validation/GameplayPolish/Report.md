## 行为变化

- 左键按下进入抬刀准备；0.18 秒之前松开为斩击，抵扣已经经过的准备时间。继续按住进入蓄力，从按下起累计 0.80 秒达到满蓄，保持时不自动出刀，松开才突刺。
- 突刺配置此前引用普通斩击动画和判定轨迹，现改为已有 `Sword_Thrust` 与独立 `ThrustBladeTrace`，时序为 0.12／0.12／0.42 秒。动画呈现使用对应突刺轨道及阶段时间，实际刀尖与判定轨迹自动比较。
- 连击仅在普通斩击完整结束后的 0.18 秒内接受新按下；恢复取消、重置和慢帧超时均关闭窗口。处决仍优先于连击与准备。防御取消后摇不会附送弹反窗口，之后重新按下防御可正常弹反。
- 攻击／恢复／顿帧中收到的攻击按下不缓存；顿帧中松开蓄力会取消。松开提交斩击／突刺时重新按既定目标优先级瞄准，并固定本次攻击方向。失焦清除准备、移动、防御及输入请求；重新按下攻击才恢复。
- 禁用或停用 CharacterController 时跳过移动和闪避位移，不产生 Unity 错误日志。恢复启用后仍使用正常角色运动；跳跃不允许空中重复起跳。
- 背包记录任务、属性、快速传送、篝火或暂停页面的返回路径。关闭后刷新该页面；属性能显示道具恢复后的最新生命。Esc 每次返回一层；直接用 C 打开的属性页返回游戏。
- 普通暂停、属性及篝火页面同样冻结镜头；背包返回暂停页时继续冻结。恢复游戏后屏蔽菜单鼠标点击，必须松开并重新按下攻击。
- 背包数量变化更新已有格子；仅新增／移除对应物品。可继续使用时保留使用按钮的键盘焦点；按钮禁用或物品耗尽时回到有效格子／分类，并确保所选格子在滚动区域内。缺失 UI 引用会给出提示并恢复可操作流程。

基线 XML 来自刚合并的背包交付记录，主分支合并没有改变这些源码。原始结果复制为 `BaselineEditMode.xml`／`BaselinePlayMode.xml`；当前为 `EditMode.xml`／`PlayMode.xml`。新增加 10 个独立 EditMode 边界用例、1 个短按／长按参数用例及 9 个 PlayMode 用例，共 20 个；没有删除测试。最后一项检查同帧松开并重按能在可行动时开始新的准备，而顿帧中的相同输入仍取消准备。

部分历史测试包含相互矛盾的预期，本轮按 README 中的既定规则修正，不能将这些用例描述为完全未改动的旧测试：

1. `HoldingPastTheWindup...` 的 0.25 秒长按原本要求“不在准备／蓄力”，现要求进入蓄力；另加 0.10 秒短按后释放斩击。
2. 两个纯 CombatCore 突刺命中测试原本在 0.25 秒才采样，此时默认突刺有效期已结束；改在 0.12 秒进入有效期时采样，伤害／架势／格挡／弹反断言保留。
3. `ThrustVisual...` 同样改在正确有效期验证 10 个刀尖位置，最大误差仍为 0.04 米。
4. `TapSlashesHoldThrusts...` 原测试名称与内容冲突，长按却要求普通斩击且不能蓄力；现实际松开短按、保持满蓄再释放，并断言突刺伤害 22。
5. 该测试原本把正常空中上升也视为二次跳跃；现直接断言空中 `TryJump` 返回 false，并检查速度没有恢复到起跳速度。
6. 背包防误攻击测试现在先断言重新按下进入准备，再松开并检查 AttackId 增加，适配恢复后的真实蓄力流程。

## 试玩清单

启动 `Builds/MilkfrogMVP-Gameplay/MilkfrogMVP.exe`，保留同目录 Data、UnityPlayer.dll 和字体许可证。

1. 单击并迅速松开左键，确认抬刀接斩击；按住至少 0.8 秒再松开，确认保持蓄力后突刺。移动镜头／目标后释放，检查攻击方向。
2. 斩击完整结束后快速再次按左键接第二刀；持续按住不自动连击。后摇早段用右键／Shift 取消，检查后续新按下正常响应。
3. 在攻击、受击、弹反顿帧中连续点击或松开蓄力，确认恢复后不会补发攻击；切出再切回窗口检查不会继续未完成的蓄力。
4. 按 B 打开背包并用鼠标／方向键／Enter 使用恢复物品，检查连续使用焦点、数量归零、滚动和禁用提示；背包原有拾取／钥匙／存档清单见历史 Inventory 报告。
5. 从任务、属性、篝火和快速传送页按 B；按 Esc 返回原页，再逐层返回游戏。使用药品后检查属性生命刷新。
6. 暂停／背包时检查镜头和战斗冻结；鼠标点击返回后继续按住左键不会攻击，松开重按后才能抬刀。
7. 在小窗口和全屏检查中文、网格、详情与滚动。试玩普通小怪及 BOSS，确认普通锁定不拖动镜头，BOSS 强制锁定保留。

当前自动化检查没有未解决失败。真人键鼠手感、完整通关和独立程序试玩仍由用户验收；不据截图声称完成这些验收。本轮未加入装备、快捷栏、制作、商店、重量、丢弃、体力或新关卡。
