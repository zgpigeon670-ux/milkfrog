# 格挡动画、BOSS 随机出招与霸体验证

日期：2026-09-24。Unity 6000.6.2f1；使用项目文件的隔离副本运行命令行测试和构建，避免与已打开的原项目 Unity 编辑器争用。未使用 Computer Use，未运行 PIE 或 Windows 程序。

## 实现

- 连击使用独立动画轨道；前摇采样从有效期之前开始，不再在进入有效期时倒退。训练场与 MVP 的动画均按 120 Hz 战斗模拟小步采样，格挡顿帧时保持当前姿势；普通格挡不中断挥刀，弹反切换到被弹反硬直。
- 仅 MVP BOSS 使用可配置的快刀／慢刀／危招加权随机，默认权重 5／3／2；慢刀和危招后下一次主动攻击必为快刀。弹反反击始终为快刀，并计入强招间隔。随机选择只在攻击提交时发生，可设置固定种子验证。
- BOSS 普通受击照常损失生命和架势，但不进入普通受击硬直；弹反、架势崩溃、死亡仍可中断攻击。小怪与原训练场继续使用原受击规则。
