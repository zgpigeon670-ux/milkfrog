# 黄牛圆形头槌（Slam）削弱修正

2026-10-16 · Unity 6000.6.2f1 · 本地 `codex/yellow-bull-boss`。

上一轮误将玩家反馈理解成直线冲撞。本轮撤回那次冲撞削弱，改为调整玩家指出的圆形范围、不可格挡的头槌；代码中的招式名为 `BullMoveKind.Slam`。保留当前其他全部工作，不推送或合并。

## 本轮调整

| 参数 | 原圆形头槌 | 调整后 |
|---|---:|---:|
| 前摇 | 1.1 秒 | 1.4 秒 |
| 命中前固定落点 | 0.4 秒 | 0.8 秒 |
| 圆形半径 | 3 米 | 1.8 米 |
| 生命伤害 | 28 | 22 |
| 架势伤害 | 30 | 24 |
| 收招 | 1.4 秒 | 1.8 秒 |

有效段仍为 0.18 秒。前摇前 0.6 秒显示“危 · 落点追踪”，之后提示“已锁点 · 离圈”，落点固定直到招式结束，不跟随之后的闪避。预警圆与实际判定共用 `Slam.range`，实际命中继续考虑玩家胶囊半径。

玩家当前一次闪避距离为 2.6 米，移动段 0.42 秒，无敌段为 0.08–0.16 秒。原半径加玩家胶囊半径达 3.4 米，单次闪避即使朝正确方向仍在范围内；新边界约为 2.2 米，提前锁点的 0.8 秒窗口允许玩家先观察再侧闪离圈。测试明确验证闪避无敌结束后，头槌尚未命中，整个有效段也不受伤。

圆形头槌继续不可格挡、不可弹反；护具减伤、闪避无敌、单次命中、架势崩溃中断均沿用统一战斗核心。配置及编辑器首次新建默认值同步，普通升级保留已有手工配置。

直线冲撞恢复为原来的前摇 1 秒、锁向 0.25 秒、速度 10、半宽 0.85、生命／架势伤害 30／32、收招 1.5 秒，二阶段第一次收招 0.25 秒；前摇期间恢复原追踪方式。删除上轮新增且针对错误招式的限速／间隔字段与 7 个削弱测试，原黄牛回归用例全部保留。冲撞预警端点共用判定前伸常量、水平行程统计的修正仍保留，不改变原招式数值。
