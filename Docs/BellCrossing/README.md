# 沉钟渡 · 奶蛙独立关卡

一座失去钟声的渡口、一座仍有人守着的旧钟院。奶蛙需要找回两枚钟印，打开北殿，击败守钟者，再亲手敲响渡钟。

## 进入关卡

- Unity 6000.6.2f1：打开 `Assets/CombatDemo/Scenes/BellCrossing.unity`，点击 Play。
- Windows：运行 `Builds/Milkfrog-BellCrossing/Milkfrog-BellCrossing.exe`；请保留同目录的数据与依赖文件。
- 从零生成场景：`Tools > Combat Demo > Bell Crossing > Create Independent Level`。
- 设计节奏目标为首次游玩约 10–15 分钟；这不是已经测得的玩家通关时间。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 / 镜头 | WASD / 鼠标 |
| 攻击 / 蓄力 | 左键短按 / 按住再松开 |
| 防御 / 弹开 | 右键按住 / 在敌人命中前按下 |
| 垫步 / 跳跃 | 左 Shift / 空格 |
| 锁定敌人 | 鼠标中键 |
| 与钟印、绞盘、留火点、供药和渡钟交互 | E |
| 回生药 | Q：恢复最多 40 生命、减少最多 15 架势 |
| 地图 / 暂停 | M / Esc |
| 完全重新开始 | 暂停或通关后按 R |

## 推荐游玩路线

1. **遗舟渡口 → 石阶哨庭**：先观察普通守卫。通过攻击、防御、弹开和垫步熟悉现有战斗。
2. **留火院**：按 E 点燃留火。激活复活点，补满生命和至少 3 份回生药。地图在这里分向西、东和北。
3. **西侧铜灯线**：经过西廊和折剑庭，到灰烬钟龛。击败钟龛守卫后按 E 取印，再到回望廊转动绞盘，打开返回门庭的捷径。
4. **东侧青灯线**：经过苇影庭，到潮声钟龛。这里有两名守卫，需要留意身侧；击败两人后取回潮声印。再沿归潮廊回到门庭。
5. **可选小祠**：从潮声钟龛向东进入无名小祠，击败守卫后可拿到额外两份药和一句碑文。
6. **双印门庭 → 静声前殿 → 守钟殿**：两印齐备后北门自动开启。进入守钟殿内部触发封门战；普通攻击可以弹开，赤色危招需要垫步回避。
7. **渡钟台**：守钟者倒下后，出口开启。走到渡钟前按 E，钟声响起并出现本关结局。

两条取印路线可以交换顺序。西侧回程栅门的绞盘只能从回望廊一侧开启，主殿门需要两枚钟印。取印不用额外背包操作。

## 死亡、补给与保存

倒下或跌出地图后，会回到已激活的留火院；尚未激活时回到渡口。本次运行取得的钟印、捷径、供药领取标记和击败记录保留，存活敌人恢复初始状态，未击败的守钟者恢复完整生命。回生药补到至少 3 份。

本关进度只保存在运行中的内存里，退出或按 R 重开后清空；不读取或写入主线存档。这里没有接入主线任务、装备成长或背包菜单，玩家与守钟者的战斗参数来自现有配置。

## 关卡结构

```text
                            [渡钟台]
                                |
                            [守钟殿]      最终封门战
                                |
                           [静声前殿]
                                |
                       双印北门（两印开启）
                                |
 [灰烬钟龛]─[回望廊]─绞盘栅门─[双印门庭]─[归潮廊]─[潮声钟龛]─[无名小祠]
      |                         |                          |
  [折剑庭]─[西廊]───────────[留火院]─────────[东廊]─[苇影庭]
                                |
                           [石阶哨庭]
                                |
                           [遗舟渡口]
```

场景由 16 个可编辑空间、17 条连接组成，统一 14 米空间单元、4 米门洞。包含 7 名普通敌人与 1 名守钟者。西线是连续单人对决，东线以双守卫场景提高注意力要求；最终战直接复用现有 Guardian 攻击配置。

## 设计意图

**先让玩家找到方向，再给出分支。** 出发段只有前进路线，留火院第一次提供选择。地纹、铜色灯与青色灯分别标记中心、西线和东线，M 地图说明双印门的位置与目标。

**走过的路应当改变。** 灰烬印之后的绞盘把西线变成环路，玩家带着新目标回到熟悉门庭。东线也在取印之后直接回到门庭，避免重复走完整条取印路线。

**让战斗节奏逐级增加。** 哨庭单敌引入操作，西线练习连续单挑，东侧钟龛安排两人对战，回到留火院恢复后再进入最终单挑。小祠把额外战斗与额外补给绑定，允许玩家自行取舍。

**终点需要一个主动动作。** 击败守钟者只是解除封锁，按 E 敲钟才完成本关，让最初的“失去钟声”和最后的声音反馈对应起来。

## 验证与限制

验证记录见 `Assets/CombatDemo/Validation/BellCrossing/Report.md`。自动化检查与摆拍截图分别记录，不能代替人工操作手感验收。当前交付使用可编辑的几何场景与材质色彩表达主题，属于可玩灰盒；没有新增角色模型、配音或跨房间寻路。

复现本关：关闭同项目编辑器后，在项目根目录分别执行 `./Tools/Validate-BellCrossing.ps1 -Stage Create`、`-Stage FocusedTests`、`-Stage Capture`、`-Stage Build`、`-Stage Smoke`。`-Stage All` 还会运行整个工程的 EditMode 与 PlayMode；其他模块的失败会使全量流程停止，具体结果见验证记录。
